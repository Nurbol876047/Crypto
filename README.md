# 🚀 Криптографиялық Escape Room — «Байқоңыр бункері: ұшыру коды»

Оқу платформасы: студенттер (жеке немесе топпен) 6 бөлмеден өтіп, әрқайсысында
бір классикалық шифрді (Цезарь, бағаналы орын ауыстыру, Виженер, Плейфер,
SHA-256 хэш, оқу RSA) өз бетінше ашады және ракетаның ұшыру кодының
фрагментін табады.

## Құрылымы

```
app.py            — Flask қолданбасы (барлық маршруттар)
db.py             — SQLite дерекқор қабаты (ORM жоқ)
quest_config.py   — config/quest.json жүктеу/сақтау, шифрмәтінді "лету" кезінде құру
crypto/           — шифрлердің өз қолмен жазылған іске асырылуы
  caesar.py
  vigenere.py
  columnar.py
  playfair.py
  rsa_utils.py
  alphabets.py
config/quest.json — квесттің барлық деректері: ашық мәтіндер, кілттер, кеңестер, рубрика
templates/        — Jinja2 HTML шаблондары
static/           — CSS және JavaScript (жиілік талдау, SHA-256/RSA калькуляторы)
tests/            — pytest тесттері (әр шифр үшін)
```

**Маңызды:** `config/quest.json` файлында және дерекқорда шифрмәтін ешқашан
дайын күйде сақталмайды — тек ашық мәтін, кілт және параметрлер сақталады.
Шифрмәтін әр рет бет жүктелген кезде `encrypt(plaintext, key)` функциясымен
қайта есептеледі.

## Орнату және іске қосу

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py
```

Қолданба іске қосылғанда `quest.db` файлы автоматты түрде құрылады.
Браузерде ашыңыз: **http://localhost:5000**

## Ойнау режимдері

- **Жеке** — атыңызды енгізіп, бункерге кіресіз.
- **Топтық** — команда атауы және 2-4 қатысушы аты.

Әр бөлме алдыңғысы шешілгеннен кейін ғана ашылады. 5 қате жауаптан кейін
жауап беру өрісі **серверде** 30 секундқа құлыпталады (тек JavaScript арқылы
емес — браузерді қайта жүктесеңіз де құлып сақталады).

## Мұғалім панелі

`http://localhost:5000/teacher` мекенжайына кіріп, құпия сөзді енгізіңіз.
Бастапқы құпия сөз `config/quest.json` файлындағы `"teacher_password"`
өрісінде тұрады (әдепкі: `baikonur2026`) — оны бірден өзгертіп алыңыз.

Панельде қолжетімді:

1. **Кезеңдер конструкторы** (`/teacher/editor/<кезең>`) — әр кезең үшін жаңа
   ашық мәтін, кілт және 3 деңгейлі кеңес енгізу. Жүйе кілтті автоматты түрде
   тексереді (мысалы, RSA үшін `p`, `q` жай сандар болуы, Плейфер үшін
   кілттің тек латынша болуы керек) және сақтағаннан кейін жаңа шифрмәтінді
   бірден көрсетеді. Сақталған соң тапсырма студенттер үшін автоматты түрде
   жаңартылады — қосымша әрекет қажет емес.
2. **«🎲 Кездейсоқ кілт жасау»** түймесі — таңдалған шифр түріне сәйкес
   кездейсоқ дұрыс кілтті ұсынады (сақтамас бұрын қарап шығуға болады).
3. **Статистика** — әр ойыншы/команда бойынша әрекет саны, қолданылған
   кеңестер, балл. `/teacher/export.csv` арқылы CSV форматында жүктеп алуға
   болады.
4. **Квест картасы** (`/teacher/map`) — барлық кезеңдердің ашық мәтіні, кілті
   және шифрмәтіні бір бетте — басып шығаруға (`🖨️`) ыңғайлы жауаптар кілті.
5. **Прогрессті нөлдеу** (`/teacher/reset`) — барлық ойыншылар мен олардың
   нәтижелерін дерекқордан толығымен жояды.

## Бағалау

Әр кезең үшін макс. 10 балл: әр кеңес үшін −2 балл, әр 3 қате әрекет үшін
−1 балл, бөлме шешілген жағдайда минимум 2 балл. Параметрлерді
`config/quest.json` ішіндегі `"scoring"` бөлімінен өзгертуге болады.

## Тесттер

```bash
source venv/bin/activate
pytest tests/ -v
```

Әр шифр үшін: қазақ және латын алфавитінде encrypt→decrypt бастапқы мәтінді
қайтаратынын тексеретін тесттер, сонымен қатар белгілі тестілік векторлар
(мысалы, классикалық Виженер мен Плейфер мысалдары) бар.

## Шифрлерді өзгерту туры

- Цезарь/Виженер/бағаналы ауыстыру: алфавит ретінде `"kazakh"` (42 әріп) немесе
  `"latin"` таңдауға болады (`crypto/alphabets.py`).
- Плейфер: тек латын алфавиті, 5×5 кесте, I мен J бір ұяшықта біріктірілген.
- RSA: `p`, `q` — 100-ден кем жай сандар; код алфавиты — цифрлар, латын
  әріптері және бос орын (37 таңба).
